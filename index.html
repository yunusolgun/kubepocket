Quick Install

Option 1 — Script (recommended for local development)

git clone https://github.com/yunusolgun/kubepocket.git
cd kubepocket
./install.sh

Auto-detects minikube, Docker Desktop, or any Kubernetes cluster.

Option 2 — Helm (recommended for production)

# 1. Install Prometheus + Grafana (required for ServiceMonitor CRDs)
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update
helm install monitoring prometheus-community/kube-prometheus-stack \
  --namespace monitoring --create-namespace \
  --set grafana.adminPassword=admin123 \
  --wait --timeout 10m

# 2. Install KubePocket (dashboard auto-imported into Grafana)
helm repo add kubepocket https://yunusolgun.github.io/kubepocket
helm repo update
helm install kubepocket kubepocket/kubepocket \
  --namespace kubepocket --create-namespace \
  --set monitoring.grafanaDashboard.enabled=true \
  --set monitoring.grafanaDashboard.namespace=monitoring \
  --wait --timeout 10m

Already have Prometheus installed? See INSTALL.md for existing stack integration.
